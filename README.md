### 함께하는 예약, 콕콕과 함께!
친구랑 같이 예약 일정 공유하고, 절대 잊지않는 콕콕 찌르기와 리마인드 알림까지!<br>
함께하는 예약을 더욱 간편하게 만들어주는 소설 예약 도우미, **KokKok**을 소개합니다.<br>
